Methods

Agentic literature review for COPD locus gene prioritization

Overview

Literature evidence supporting candidate-gene prioritization at each COPD GWAS locus was gathered using a multi-agent literature-review pipeline built on Claude Code (Anthropic).

🔍 Researcher
→
✅ Citation Verifier
→
🔴 Red-Team Critique
→
📊 Synthesis Lead

A single Researcher agent, covering statistical genetics, pulmonary structural/developmental biology, and immunology/inflammation, searched for literature bearing on every candidate gene at each locus, using PubMed and bioRxiv/medRxiv as primary sources.

Every candidate citation was then passed through an independent Citation Verifier agent, which confirmed the citation's existence via PubMed E-utilities and/or Crossref, checked retraction status, and confirmed the cited abstract actually supported the claim attributed to it.

Verified findings were then critiqued by an adversarial Red-Team agent for LD/nearest-gene bias, smoking confounding, contradicting evidence, and overclaiming, before a final Synthesis Lead agent assembled the per-locus evidence table.

The synthesis-lead agent additionally queried the Open Targets Platform (locus-to-gene score, colocalization evidence, and genetic constraint) directly for each candidate gene at each locus; this structured database lookup is reported separately from the literature-derived evidence table, since it did not pass through the citation-verification or red-team-critique steps described below.

All citations in the reported evidence tables carry a VERIFIED status from this pipeline; rejected and contested citations are preserved in a per-locus audit appendix (kept in a separate audits/ directory from the evidence tables) rather than discarded.

Citation Verification Protocol

See .claude/agents/citation-verifier.md for the full protocol. In summary:

  • Existence — confirmed against PubMed E-utilities or Crossref (not against the model's own training knowledge).
  • Retraction status — checked against PubMed's integrated Retraction Watch data and, where inconclusive, the Retraction Watch database directly.
  • Claim correspondence — confirmed by quoting the specific supporting sentence from the primary source's abstract.

Reproducibility

The full agent configuration (system prompts, tool access, model assignments) is version-controlled in this repository. logs/agent_model_registry.json records, per session, a hash of each agent's exact system prompt, so a reviewer can confirm which instructions were in effect for a given evidence table without re-running anything.

Limitations

This pipeline reduces, but does not eliminate, the risk of literature-review error inherent to LLM-assisted search: domain-expert agents may still miss relevant literature or mischaracterize a finding before verification catches a fabricated identifier; the verification step checks existence, retraction status, and quote-level correspondence, but does not independently assess study quality or effect-size adequacy.
