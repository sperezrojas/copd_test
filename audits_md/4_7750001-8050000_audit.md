# Audit trail — Locus 4:7,750,001-8,050,000 (AFAP1)

This file preserves the excluded citations, contested/weakened verdicts, and process gaps for
this locus, for reviewer transparency. It is a companion to
`evidence_tables/4_7750001-8050000.md` and should not be distributed as part of the clean
evidence table.

## Excluded citations (RETRACTED / NOT_FOUND / CLAIM_MISMATCH)

No citations in this locus's packet were RETRACTED or NOT_FOUND. Five were CLAIM_MISMATCH —
i.e. the paper genuinely exists and its general description was accurate, but the specific
claim that AFAP1 is named/discussed in it could not be confirmed from the abstract:

1. **Shrine N et al., "New genetic signals for lung function..." Nat Genet 2019;51(3):481-493.
   PMID 30804560.** CLAIM_MISMATCH — paper exists, description of scale (~400,102
   individuals, 279 lung-function signals) is accurate, but AFAP1 is not named in the
   abstract. Gene-level attribution to AFAP1 is unconfirmed (may appear only in a
   supplementary locus table not indexed by abstract search).

2. **Shrine N et al., "Multi-ancestry genome-wide association analyses..." Nat Genet
   2023;55(3):410-422. PMID 36914875.** CLAIM_MISMATCH — same issue; 1,020 signals/559 genes
   description accurate, AFAP1 not named in abstract.

3. **Wyss AB et al., "Multiethnic meta-analysis identifies ancestry-specific..." Nat Commun
   2018;9(1):2976. PMID 30061609.** CLAIM_MISMATCH — cohort description (N=90,715) accurate,
   AFAP1 not named in abstract.

4. **Zhou W et al. (Global Biobank Meta-analysis Initiative), Cell Genomics 2022;2(10):100192.
   PMID 36777996.** CLAIM_MISMATCH — paper exists (>2.2M individuals, 23 biobanks, "14
   exemplar diseases"), but abstract does not enumerate which diseases are covered, so
   whether COPD specifically is included (let alone AFAP1) is unconfirmed.

5. **You D et al., "A genome-wide cross-trait analysis characterizes..." Nat Commun
   2025;16(1):3032. PMID 40155373.** CLAIM_MISMATCH — 66 candidate pleiotropic genes
   description confirmed, but abstract does not list gene names, so AFAP1 is not confirmed
   among them.

## Gene-level skeptic verdict

**AFAP1: WEAKENED** (red-team-skeptic verdict, not CONTESTED). Full reasoning is reproduced
in `evidence_tables/_status/4_7750001-8050000/critique.md`; summary: the statistical/
fine-mapping case for AFAP1 as the physically-implicated gene at this locus is comparatively
clean (single gene body, all 39 credible-set variants intronic to it, three concordant
prioritization methods, spirometric-trait concordance, no smoking-pathway confound, one
confirmed named replication in Lin WD 2024). But the inference that AFAP1 is a
mechanistically confirmed pulmonary-disease gene overreaches the evidence: most of the
statistical-genetics citation list does not name AFAP1 at all (5 of 10 were CLAIM_MISMATCH),
there is zero pulmonary mechanistic/expression/functional evidence anywhere in the structural
or immune literature, and the gene's only well-validated human functional biology is ocular
(primary open-angle glaucoma/intraocular pressure), with a lead-variant-level pleiotropy
signal (rs73073939 itself resolving to a glaucoma credible set in Open Targets, L2G=0.78)
that remains unresolved for lack of a colocalization analysis. No paper argues AFAP1 is the
wrong gene or that a different gene at this locus is causal for COPD (hence not CONTESTED),
but that check could not be independently run this pass due to the search-budget exhaustion
noted above.
